# Embedded C on the Arduino Uno R3

A student-friendly course for the ATmega328P on the Arduino Uno R3. Start with [`tutorials/welcome.md`](tutorials/welcome.md). The published course is at <https://www.arnabkumardas.com/learn/atmega328p/>.

This repository contains Markdown lessons, rendered course images, and the HAL and lab repositories as Git submodules. Clone it with `git clone --recurse-submodules <repository-url>` to download the firmware repositories with the lessons.
